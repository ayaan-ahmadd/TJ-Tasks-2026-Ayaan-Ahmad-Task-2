# TJ-Tasks-2026-Ayaan-Ahmad-Task-2

Pulaowala

A simple and responsive restaurant website for Pulaowala, a Bihar cuisine restaurant serving authentic Bihari Pulao, Chicken, Mutton and Bihari Kebabs.

About the Project

Pulaowala is a restaurant website created to showcase the restaurant, its menu, story, contact information, and reservation options.
Pulaowala was started in December 2023 on 40 Foot Road, Shaheen Bagh, New Delhi. The restaurant focuses on authentic Bihari flavors and has served 100,000+ orders.
I made this project to practice frontend web development and get a better understanding of how HTML, CSS work together to create a responsive and user-friendly website.
I created this website after learning the basics of HTML, CSS. I tried to apply the concepts I had learned and build a complete website based on my current knowledge.

Approach

I started by planning the basic structure of the website and deciding what sections would be useful for a restaurant website.
HTML was used to create the structure of the website, including the navigation, menu, about section, contact section, reservation form, and footer.
CSS was used for the layout, typography, colors, spacing, buttons, animations, and responsive design.
I built the website step by step and focused on creating a clean restaurant-oriented design while making sure the website works across different screen sizes.
